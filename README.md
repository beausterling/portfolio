# Portfolio

My personal e-portfolio, built in the advanced project of my web dev course.

Live site: https://beausterling.github.io/portfolio/

## What's on the page

- Landing page with a big intro, social links and a scrolling mouse icon
- Background shapes that move with your mouse
- Light and dark mode toggle
- About me and contact modal that slides in from both sides
- Contact form with loading and success states (sent with EmailJS)
- Projects section with a blur and slide-up hover effect
- Footer with links back to the contact form

## Built with

- HTML
- CSS (Flexbox, transitions, keyframe animations, media queries)
- JavaScript (event listeners, promises)
- [EmailJS](https://www.emailjs.com/) for the contact form
- Font Awesome icons and Devicon logos

## Contact form setup

The form needs an EmailJS account. Put your service ID, template ID and public key at the top of `index.js`. Until then the form just shows a message asking people to reach out on GitHub.
